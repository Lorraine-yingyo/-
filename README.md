# 条件实验室 · 自然语言选股与策略解释器

把“经营改善、估值合理、走势相对稳定”转成可检查、可修改的指标条件，再用确定性引擎解释每只公司为什么入选、为什么被排除、缺少哪些证据。面向同花顺题目 02 的可运行作品。

**当前版本：规则解析 + 12 家公司的真实历史样本。默认没有连接大语言模型；可选通用兼容模型适配器已实现但未做真实账号调用。不展示为实时行情，不提供全市场选股、收益预测或买卖建议。** 扶摇财务接口适配器已实现，未配置有效权限时明确返回未接入。文档入口本身不是 API 调用凭证。

## 产品选择与主链路

首版聚焦一条可以验证的链路：输入意图 → 确认口径和阈值 → 检查冲突 → 确定性筛选 → 查看入选、排除和未知依据 → 修改阈值、比较公司、保存条件。

界面采用蓝灰配色，提供三步首次引导、三个明确阈值的快捷预设、行内添加条件、可切换升降序的指标表头及手机公司卡片。统计卡片只计算已应用条件下符合条件的公司；PE 放宽提示按其他条件不变时的实际新增数量计算。完成引导后在当前浏览器保存 `condition-lab-tour-v1=true`，也可从“使用引导”再次打开。

“经营改善”被解释为可修改的增长阈值，不被描述成模型已经理解了企业经营质量。“估值合理”只是一个需要用户确认的 PE 条件；负 PE 不判为便宜。浏览器中的保存仅保存在当前设备，不是云同步或交易监控。历史样本数据和阈值并不构成投资建议。

| 层次 | 文件 | 职责 |
| --- | --- | --- |
| 界面 | `app/page.tsx` | 呈现待确认条件、逐项证据、来源与操作 |
| 自然语言入口 | `app/api/interpret/route.ts` | 输入校验；默认规则，可选模型转译，错误时显式回退 |
| 规则与筛选 | `lib/screening.ts` | 解析受支持表达、识别冲突、执行比较、解释未知与排除 |
| 数据适配器 | `lib/providers.ts`、`app/api/data/route.ts` | 凭有效 key 调用扶摇财务接口，处理业务错误、超时与缺失 |
| 历史证据 | `data/snapshot.json`、`data/raw/` | 保存逐字段来源、原始响应与复现依据 |

## 数据与时间边界

默认是 **2024 年报 × 2025-04-30 的估值与波动率**，12 家固定公司，来自公开数据接口并保存原始响应。抓取时间为 2026-10-13；财务源中存在后续更新与回填。因此它是**当前可得的历史数据，不是 2025-04-30 当时的信息集**，不能用于证明历史策略收益或无前视偏差的回测。

波动率由 61 个真实后复权收盘价产生 60 个日对数收益率，以样本标准差乘以 `sqrt(252)` 年化。其他指标沿用明确的源字段。数据缺失保留 `null`，不填 0；负 PE 视为不适用。详见 [数据来源与复现](docs/DATA_SOURCES.md)。

## 可选模型配置

如已有兼容 Chat Completions 协议的服务，可在服务端同时配置 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL`。三者缺一即保持规则模式；没有默认服务商、URL 或模型，也不会自动申请账号或密钥。`AI_BASE_URL` 是 `/chat/completions` 之前的 HTTPS 基础路径。接口需支持 `messages` 与 `response_format: { type: "json_object" }`。

模型只输出五个允许指标、`gte/lte` 运算符和数值；服务端严格校验 schema、白名单、数值及条件冲突。模型自由说明不会直接进入页面：危险内容拒绝并回退，其余内容用服务端根据指标和阈值生成的中性说明替换。每次返回的候选条件均需用户检查确认；模型不执行筛选。超时、格式错误或不合法输出会明确返回 `mode: rules`、`fallback: true`、错误码及重新确认提示，不能把回退说成模型成功。配置状态仅表示变量齐备，不代表真实连通性或模型效果已经通过验证。输入的选股描述将在用户发起解析时发送到配置的服务；不发送本地保存的策略或持仓。

## 可选扶摇权限

当前主链路不需要密钥。接入真实扶摇财务接口时，可参考 `.env.example` 在本地受忽略的环境文件或托管平台 secret 配置 `FUYAO_API_KEY`，不要把密钥放入浏览器、源码仓库或聊天。Cloudflare 环境使用服务端绑定；Node 环境使用 `process.env`。配置后重启，并用 `/api/status` 检查配置布尔值；配置存在不代表认证成功。

- `GET /api/status`：仅返回接入状态，不返回密钥。
- `POST /api/interpret`：JSON `{ "text": "营收增长至少5%，PE不超过30倍" }`；1–1000 字，默认规则解析结果；模型变量完整时尝试模型转译。
- `POST /api/data`：JSON `{ "codes": ["600519.SH"], "report": "2024-4" }`；最多 12 个代码。未配置 key 返回 503；全部请求失败返回 502；部分成功逐条保留错误。

适配器只请求固定扶摇域名，禁止重定向，单股超时 8 秒，并发最多 4，校验 HTTP 与业务 `code`，限制请求和响应大小。它没有接入完整实时估值和日线。扶摇“营业收入”与样本“营业总收入”、“净利润”与样本“归母净利润”的口径不能默认等同；保留原始命名字段，统一筛选字段保持未知。部分成功明确标记 `partial: true`、`completeForScreening: false`，不会偷偷用历史样本补齐。
