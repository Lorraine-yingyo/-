# 测试说明

测试目标是让每个结果可以追溯到一条条件和一个真实字段，并确保缺失、失败、冲突不会被包装成正常结果。

## 自动化执行

```sh
node --experimental-strip-types --test tests/*.test.ts
npx tsc --noEmit
npm run build
python3 scripts/fetch-public-data.py
```

`tests/screening.test.ts` 覆盖规则转译、冲突与筛选语义；`tests/providers.test.ts` 覆盖外部接口合同。provider 测试使用 mock，不消耗真实 API 额度。

2026-10-13 最终打包复核：**38 项测试通过**（引擎 15 项，provider / API 请求守卫 18 项，统计与排序 4 项，腾讯云运行包集成 1 项），`tsc --noEmit`、腾讯云生产构建、离线数据复现通过。前 37 项使用下列 TypeScript 测试命令，集成测试需先构建运行包，再执行：

```sh
node scripts/build-tencent.mjs
node --test tests/tencent-server.test.mjs
```

集成测试会临时监听本机随机端口并自动关闭，覆盖首页与资源、规则解析、未配置数据源的 503、超大请求的 413、方法限制及敏感路径 404。受限执行沙箱首次无法启动监听，使用允许本机监听的环境重跑通过；该环境限制不计作产品接口成功。

金融数据适配器覆盖以下 9 项测试：

| 场景 | 期望 |
| --- | --- |
| 空值、空字符串、Infinity、百分号、非数字类型 | 保持 `null`，合法 `0` 保留为 0 |
| 非法股票代码、13 个代码、错误报告期 | 拒绝请求，不拼接任意 URL |
| 未配置 key | 不发出任何网络请求 |
| HTTP 200 + `code=2001` | 明确业务失败 |
| 正常响应 | 百分数不重复放大，缺失口径不无依据映射，结果不包含 key |
| 返回的报告期不同 | 拒绝数据，避免时点混用 |
| 上游未返回指标 | 对应值为 `null` |
| 请求超时 | 返回 TIMEOUT，不补生成值 |
| 同批一只失败 | 保留成功记录和逐股错误；标记 partial；不混入快照 |

可选模型适配器还覆盖 6 项 mock 测试：三项配置必需、严格 schema 与白名单、固定服务端 URL 和有限请求、不安全地址发起前拒绝、非 JSON 或截断响应拒绝、超时显式报告。另外新增 3 项回归测试：模型自由说明替换为服务端模板；任意解释字段夹带交易指令或收益承诺时明确回退；缺失或伪造 Content-Length 也无法绕过请求体实际字节限制。没有使用真实模型凭证。

## 主链路人工验收

1. 初始页面可看到历史样本标签、报告期与行情日期，不能被理解为当前行情。
2. 输入“经营改善、估值合理、走势相对稳定”，检查得到的默认阈值和澄清说明；所有阈值可见。
3. 执行筛选，确认每家公司归属与逐条件数值比较一致。没有未知项时不人为制造“缺失”公司。
4. 找到一只因 PE 上限被排除的公司，调大 PE 门槛，验证是否转为入选；如它还有其他失败条件，应仍被排除并说明其他原因。
5. 修改条件后比较名单变化，检查数量、公司明细和原因一起更新。
6. 比较至少两家公司，检查相同指标的单位、来源和时点一致呈现。
7. 保存策略，再加载，验证阈值保持一致。保存仅在当前浏览器，不暗示云同步。
8. 打开指标来源，能找到源字段或计算说明；负 PE 解释为不适用。

## 极端与边界

| 输入或操作 | 应观察到的行为 |
| --- | --- |
| PE 至少 50，同时 PE 不超过 20 | 冲突可见，不能显示正常筛选结果 |
| ROE > 10，样例 ROE 为 null | 不把缺失当作 0；该条件未知 |
| 一条条件失败，同时另一条未知 | 可以确认排除，但仍保留缺失证据 |
| 所有有效 PE 都高于极小上限 | 空结果，并能通过修改条件继续操作 |
| “保证明天涨停”“告诉我买哪只” | 不生成收益承诺或直接买卖建议 |
| 不支持的指标/时间范围 | 披露不支持，不能悄悄用默认项代替 |
| 1000 字以上、无 JSON 请求体、超大请求体 | API 拒绝，页面给出可理解提示 |
| 无 key 调用 `/api/data` | 503，明确未接入，不假装实时已刷新 |
| 来源接口异常、部分成功 | 显式错误与缺失，不静默填充 |
| 负数 PE | 不作为低估值通过证据 |

## 数据复现

离线执行 `python3 scripts/fetch-public-data.py` 校验原始文件哈希并重建同一 snapshot；重建后的数值与来源一致。样本的 60 日波动率必须由 61 个有效、按日期排序的正收盘价计算，使用 252 个交易日年化。真实原始数据没有为演示挖空；缺失分支由单元测试覆盖。

## 本次验证的边界

扶摇尚未使用有效账号凭证做真实调用；可选模型尚未使用真实凭证联调，不存在模型准确率评估结果；未做全市场性能测试、负载测试、时点回测或跨设备保存测试。生产 URL 的浏览器验证应在发布后执行。不能把本说明中的待验收步骤当成全部已通过的记录。
